# Inspire Hand Asset Attribution

The Inspire hand geometry and model description are derived from the Inspire Hand model distributed through [DexSuite dex-urdf](https://github.com/dexsuite/dex-urdf/tree/main/robots/hands/inspire_hand), based on CAD files provided by [Inspire Robotics](https://www.inspire-robots.com/download/frwz/). DexSuite identifies the Inspire model as **CC BY-NC-SA 4.0**. See the [Creative Commons license](https://creativecommons.org/licenses/by-nc-sa/4.0/) and the upstream [`LICENSE.txt`](https://github.com/dexsuite/dex-urdf/blob/main/robots/hands/inspire_hand/LICENSE.txt).

FoLD's runtime URDFs are adapted for the simulator: they include wrist/inertial compatibility edits and use selected GLB visual meshes. The STL and GLB geometry is redistributed with the attribution and under the applicable upstream terms. These hand assets are not covered by FoLD's software license.

The exact upstream commit used for the local copy was not recorded. The source filenames and mesh layout match the Inspire asset bundle in the [DexMachina repository](https://github.com/MandiZhao/dexmachina/tree/main/dexmachina/assets/inspire_hand).
